## Lecture 7.2: Modern Architecture for Deep Learning

> - CNN 为什么适合图像
> - 卷积、padding、stride、pooling 的含义和公式
> - RNN 为什么适合序列
> - RNN、LSTM、GRU 的核心结构与差别

### 这一讲在讲什么

这一讲的主线其实很明确：不同类型的数据，适合不同结构的神经网络。

- 如果数据是图像，关键结构是“局部空间关系”，所以需要 CNN。
- 如果数据是序列，关键结构是“前后顺序与历史依赖”，所以需要 RNN。
- 如果普通 RNN 学不动长期依赖，就进一步引入 LSTM 和 GRU。

如果复习时只记一句话，那么可以记成：

> CNN 解决“图像怎么高效建模”，RNN 解决“序列怎么把过去的信息带到现在”。

### Section 1: CNN

### 为什么全连接网络不适合直接处理图像

假设输入是一张尺寸为 $32 \times 32 \times 3$ 的 RGB 图片。

- 如果直接接一个有 1000 个隐藏单元的全连接层，那么仅这一层的参数量就是 $32 \times 32 \times 3 \times 1000$，非常大。
- 更重要的是，全连接层并没有利用图像本身的结构。它把每个像素都视为“同等地位”的输入，而没有利用“相邻像素通常更相关”这一事实。

图像有两个非常重要的特点：

- 局部性：边缘、角点、纹理等模式通常只和局部邻域有关。
- 平移复用性：同一种模式可能出现在图像的不同位置，比如猫耳朵可以在左上角，也可以在右上角。

CNN 正是针对这两个特点设计的。

### CNN 的核心思想

CNN 的两个关键词是：

- 局部连接（local connectivity）
- 参数共享（parameter sharing）

局部连接表示：一个神经元不需要连接整张图，只需要看一小块区域。

参数共享表示：同一个卷积核在整张图上反复滑动，寻找相同模式。也就是说，不管边缘出现在左边还是右边，我们都用同一组参数去检测它。

这带来两个直接好处：

- 参数量大幅减少
- 模型天然具备“在不同位置识别同一模式”的能力

### 什么是卷积

可以把卷积理解成：用一个小窗口在图像上滑动，并在每个位置计算“这个局部区域和某种模式有多像”。

这个“小窗口”就是卷积核（filter 或 kernel）。

如果输入是二维图像 $X$，卷积核是 $K$，那么某个位置上的输出可以写成：

$$
Y(i,j) = \sum_u \sum_v X(i+u, j+v)K(u,v).
$$

直观上，它是在做局部加权求和。

如果卷积核学到的是“横向边缘检测器”，那么输出大的地方就说明这个局部区域存在横向边缘。

### Feature Map 是什么

一个卷积核扫完整张图后，会得到一张新的二维图，这张图叫 feature map。

- 输入图像回答的是“原始像素是什么”
- feature map 回答的是“某种局部模式在什么地方出现了”

通常一个卷积层不会只用一个卷积核，而会同时用很多个卷积核。

- 有的核学边缘
- 有的核学角点
- 有的核学纹理
- 更深层还会学到更复杂的结构，比如眼睛、轮廓、部件等

### CNN 为什么比全连接层参数少

这是理解 CNN 很重要的一点。

假设输入是 $32 \times 32 \times 3$，使用 64 个 $3 \times 3$ 卷积核。

每个卷积核的参数量是：

$$
3 \times 3 \times 3 = 27
$$

如果再加一个偏置，大约是 28 个参数。

64 个核总共大约是：

$$
64 \times 28
$$

这远小于全连接层的参数量。原因就在于同一个核在整张图上共享使用，而不是每个空间位置都各自拥有独立参数。

### Padding 是什么

卷积时，如果不做任何处理，卷积核每滑一次都会“吃掉边界”，导致输出尺寸越来越小。

padding 的做法是在输入边界外补零。

作用有两个：

- 保留边界信息
- 控制输出尺寸

最常见的是 zero padding。

如果输入宽高是 $W$，卷积核大小是 $F$，padding 是 $P$，stride 是 $S$，那么输出尺寸通常写成：

$$
\text{output size} = \frac{W - F + 2P}{S} + 1.
$$

这个公式复习时非常值得记住，因为很多题都会让你算输出尺寸。

### Stride 是什么

stride 表示卷积核每次滑动跨几格。

- stride = 1：每次移动一格，输出更细致
- stride = 2：每次移动两格，输出更小、更粗略

因此 stride 控制的是下采样速度和输出分辨率。

### 一个卷积层到底在做什么

一个典型卷积层通常包含以下步骤：

1. 用若干卷积核对输入做卷积
2. 加偏置
3. 经过非线性激活函数，例如 ReLU
4. 输出多个 feature maps

所以它不是简单的“图像滤波”，而是“带参数、可学习的局部特征提取器”。

### Pooling 是什么

pooling 不是再学一层新特征，而是对已有特征图做压缩。

最常见的是：

- max pooling
- average pooling

#### Max Pooling 的直觉

在一个局部窗口里，只保留最大值。

它相当于在问：

> 这个局部区域里，这个模式最强出现在哪里？

所以 max pooling 更强调“是否出现过强响应”。

#### Average Pooling 的直觉

在一个局部窗口里取平均值。

它相当于在问：

> 这个局部区域整体响应强不强？

所以它更平滑，但通常没有 max pooling 那么强调局部显著特征。

### CNN 为什么有效

如果复习时想系统回答“为什么 CNN 对图像有效”，可以从四点说：

1. 利用了图像的局部相关性
2. 通过参数共享大幅降低参数量
3. 可以逐层抽取从低级到高级的视觉特征
4. 对平移和局部形变具有一定鲁棒性

这四点基本就是 CNN 的全部核心直觉。

### 一个典型的 CNN 流水线

一条很常见的结构是：

输入图像 → 卷积层 → 激活函数 → pooling → 卷积层 → pooling → 全连接层 → softmax

理解这条流水线时，可以这样记：

- 前面卷积部分负责“抽特征”
- 后面全连接部分负责“做分类”

### CNN 的局限

虽然 CNN 对图像很强，但也有局限：

- 它主要擅长处理规则网格数据，如图像
- 对长距离依赖建模不如注意力机制灵活
- 对几何结构变化较大的任务，有时需要更复杂结构

### Section 2: Recurrent Neural Network

### 为什么需要 RNN

如果数据是序列，那么顺序本身就是信息。

例如一句话中：

- “I am not happy”
- “I am happy not”

词是类似的，但顺序一变，意义就变了。

普通前馈网络的问题在于：

- 它把输入视为静态向量
- 它不会自动记住“前面出现过什么”
- 它不适合处理可变长度输入

这时就需要一种结构，能够把过去的信息带到当前时刻，这就是 RNN。

### RNN 的核心思想

RNN 的关键是隐藏状态（hidden state）。

在时间步 $t$，RNN 不只看当前输入 $x_t$，还看前一个时刻的隐藏状态 $h_{t-1}$。

因此：

$$
h_t = f(W_x x_t + W_h h_{t-1} + b).
$$

如果还要输出结果，则可写成：

$$
y_t = g(W_y h_t).
$$

这个式子是理解 RNN 的核心。

它表示：

- $x_t$ 提供当前新信息
- $h_{t-1}$ 提供历史记忆
- $h_t$ 是“当前信息 + 历史信息”融合后的结果

### 如何理解隐藏状态

可以把隐藏状态理解成一句话的“到目前为止的压缩摘要”。

例如处理句子时：

- 第一个词读完后，有一个摘要
- 第二个词读完后，摘要更新
- 第三个词读完后，再更新

这个摘要不断被传下去，所以 RNN 理论上可以记住过去。

### RNN 适合做什么

RNN 天然适合处理：

- 文本序列
- 语音信号
- 时间序列数据
- 任意具有前后依赖的输入

因为这些任务的关键不只是“当前元素是什么”，而是“它之前发生了什么”。

### RNN 的结构变体

讲义里提到几种常见结构：

- 标准 RNN
- Deep RNN
- Bidirectional RNN

#### Deep RNN

表示在每个时间步内部再堆多层隐藏层，从而增强表达能力。

#### Bidirectional RNN

表示同时从左到右和从右到左读序列。

这适合那些“整个序列都已知”的任务，比如序列标注，因为当前词的理解可能既依赖左边也依赖右边。

### RNN 的训练困难

普通 RNN 虽然概念简单，但训练时有一个致命问题：长期依赖很难学。

原因在于反向传播要跨很多时间步展开，梯度会反复相乘。

如果这些乘积的模长持续小于 1，就会：

- vanishing gradient

如果持续大于 1，就会：

- exploding gradient

这就是为什么普通 RNN 往往只能较好处理短期依赖，而很难真正“记住很久以前的信息”。

### LSTM 为什么出现

LSTM 的目标很明确：

> 让网络有能力选择“哪些信息该保留很久，哪些信息该丢掉”。

所以 LSTM 的核心不是“多加几层”，而是“加入门控机制”。

### LSTM 的核心结构

LSTM 里最关键的是 cell state。

可以把它理解成一条专门用来长期保存信息的“主通道”。

围绕这条主通道，LSTM 设计了若干门：

- forget gate：决定丢掉什么
- input gate：决定写入什么
- output gate：决定输出什么

#### Forget Gate

它回答的问题是：

> 旧记忆里哪些该保留，哪些该忘掉？

#### Input Gate

它回答的问题是：

> 当前新输入里，哪些值得写进长期记忆？

#### Output Gate

它回答的问题是：

> 当前时刻应该把长期记忆的哪些部分暴露给外部？

### LSTM 为什么能缓解长期依赖

因为它不再要求所有信息都经过同一种非线性递归反复压缩，而是单独保留了一条更稳定的记忆通道。

因此，信息可以在更长时间范围内传递，梯度也更容易沿着这条路径传播。

这就是 LSTM 相比普通 RNN 最本质的进步。

### GRU 是什么

GRU 可以看成 LSTM 的简化版。

它保留了“门控”这个核心思想，但结构更简单。

通常 GRU 主要包含两个门：

- update gate
- reset gate

#### Update Gate

决定当前状态中保留多少旧信息、接纳多少新信息。

#### Reset Gate

决定在生成当前候选状态时，要不要强烈依赖过去。

### GRU 和 LSTM 的区别

如果复习时想一句话区分它们，可以这样记：

- LSTM 更完整，有显式 cell state，表达更强
- GRU 更简洁，参数更少，训练更轻量

通常：

- 如果想要更强记忆机制，可以选 LSTM
- 如果想结构更简单、训练更快，GRU 往往是很好的折中

### CNN 与 RNN 的本质差异

这也是这一讲最值得总结的一点。

#### CNN

- 处理对象：图像、二维网格
- 关注重点：局部空间结构
- 核心机制：卷积核共享 + 空间滑动

#### RNN

- 处理对象：序列
- 关注重点：前后顺序与历史依赖
- 核心机制：隐藏状态递推

所以不要把 CNN 和 RNN 仅仅当成“两种网络名字”。

它们其实是在回答两个完全不同的问题：

- 图像里，模式出现在什么位置？
- 序列里，过去的信息如何影响现在？
