### Part 1: LLM Training Pipeline

### 两阶段训练流程

现代 LLM 的训练通常不是一步完成，而是分成两个阶段：

1. Pre-training
2. Post-training

可以把它们理解成：

- pre-training：先学“语言本身”
- post-training：再学“怎样更像一个可用助手”

### Pre-training 在做什么

pre-training 的目标是让模型通过海量文本，学会：

- 语言统计规律
- 词和词之间的关系
- 世界知识的部分表征
- 推理和模式迁移的基础能力

最典型的训练目标就是 next-token prediction。

也就是说，模型不断回答：

> 给定前文，下一个 token 最可能是什么？

### Pre-training 的基本流程

这一部分可以按流水线记忆：

#### Step 1: Data Collection

收集大规模文本数据。

#### Step 2: Data Preprocessing

对文本做清洗、去重、过滤、分词等预处理。

#### Step 3: Model Architecture

选择模型结构，通常是 Transformer。

#### Step 4: Training Objective

确定训练目标，最常见是自回归语言建模。

#### Step 5: Optimization

用大规模分布式训练来更新模型参数。

#### Step 6: Evaluation & Scaling

边训练边评估，并根据性能决定是否继续增加数据、算力或参数规模。

### Post-training 在做什么

pre-training 得到的模型，往往只是“会续写文本”。

但真正可用的助手还需要：

- 更符合人类偏好
- 更遵从指令
- 更安全
- 更稳定

这就是 post-training 或 alignment 阶段的目标。

你可以把这一步理解成：

> 从“会说话的模型”变成“更可控、可交互的模型”。

### Scaling Laws 是什么

scaling laws 研究的是：

> 当模型更大、数据更多、算力更强时，性能到底怎样变化？

这件事很重要，因为大模型训练成本极高，必须知道“继续放大值不值得”。

### 为什么 scaling laws 重要

它们帮助我们回答：

- 应该优先加模型参数，还是优先加数据？
- 给定固定算力，什么配置更划算？
- 性能提升会不会很快饱和？

### Chinchilla 给出的启发

Chinchilla 的一个重要结论是：

> 模型变大不是唯一目标，模型规模和训练 token 数量之间需要平衡。

也就是说，固定计算预算下，参数和数据不是越大越随意越好，而是有更合理的搭配关系。

### Emergence 是什么

随着模型规模变大，模型有时会突然展现一些小模型没有明显表现出的能力，这被称为 emergence。

它说明规模增长并不只是“线性增强”，有时还会伴随能力层级的变化。

### 为什么 GPU 对深度学习如此关键

深度学习最核心的计算之一是矩阵乘法。

而矩阵乘法有一个特点：

> 它天然非常适合并行。

GPU 相比 CPU 的优势就在于：

- 同时做很多运算
- 非常适合张量和矩阵操作
- 与神经网络训练模式高度匹配

所以“为什么深度学习崛起”和“为什么 GPU 普及”之间，其实有很强联系。

### Multi-GPU / Multi-Node 为什么麻烦

单张 GPU 的显存和算力都有限。

大模型训练往往必须跨：

- 多张 GPU
- 多台机器

这时难点不再只是“算得快不快”，还包括：

- 数据怎么分
- 参数怎么同步
- 通信开销有多大
- 系统如何稳定

所以现代 LLM 训练是算法、硬件和系统工程共同作用的结果。

### Part 2: Graph Neural Network

### 为什么需要图神经网络

普通神经网络最擅长处理三类数据：

- 向量
- 图像网格
- 序列

但很多现实数据天然不是这些形式，而是图：

- 社交网络
- 分子结构
- 知识图谱
- 推荐系统中的用户-物品关系

这些数据的关键信息，不只是“每个对象本身长什么样”，而是“对象之间怎么连接”。

这就需要 Graph Neural Network。

### 图数据的核心特点

图由两部分组成：

- 节点（node）
- 边（edge）

节点表示对象，边表示对象之间的关系。

所以图学习的本质问题通常是：

> 怎样把“关系结构”也纳入表示学习中？

### GNN 的核心思想：Message Passing

GNN 最重要的思想就是 message passing。

一个节点不会只看自己，而是会从邻居节点收集信息，再更新自己的表示。

所以一层 GNN 可以理解成两步：

1. 聚合邻居信息
2. 更新当前节点表示

如果堆很多层，那么一个节点就能逐步“看见”更远范围的结构。

### 为什么 message passing 有效

因为图上的很多任务本来就依赖邻域信息。

例如：

- 一个用户喜欢什么，常和相似用户有关
- 一个分子的性质，常和相邻原子结构有关
- 一个网页的重要性，常和它连接到哪些网页有关

message passing 恰好是在做这种“从邻域吸收信息”的过程。

### GCN 是什么

Graph Convolutional Network 可以理解为：

> 把卷积的思想从规则网格推广到图结构上。

在图像里，卷积是在固定邻域上做局部汇聚；
在图里，GCN 则是在图邻接结构定义的邻域上做汇聚。

所以复习时可以这样类比：

- CNN：邻域由像素网格决定
- GCN：邻域由图的边决定

### GAT 是什么

Graph Attention Network 的关键改进是：

> 不同邻居不一定同样重要。

GCN 往往对邻居做较均匀的聚合，而 GAT 会为每个邻居分配不同权重。

这让模型更灵活，因为它能自动学习：

- 哪些邻居更值得关注
- 哪些关系更关键

### GNN 能做什么任务

常见图任务包括：

- 节点分类
- 图分类
- 链接预测
- 推荐
- 分子性质预测

所以 GNN 不是一个单一任务模型，而是一类“面向图结构数据”的通用建模框架。

### GNN 面临的挑战

虽然 GNN 很自然，但也不是什么都简单。

常见问题有：

- 大规模图训练困难
- 图结构可能异质、动态、带噪
- 过多层会出现 over-smoothing
- 可解释性仍然困难
